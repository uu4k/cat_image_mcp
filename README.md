# cat_image_mcp

このリポジトリは、ランダムな猫画像を取得するAPIやサンプルコードを提供するプロジェクトです。

## 概要
- ランダムな猫画像を取得できるエンドポイントを実装
- サンプルとしてAPIの呼び出し例も掲載

## 使い方
1. リポジトリをクローンします。
   ```sh
   git clone https://github.com/uu4k/cat_image_mcp.git
   ```
2. 必要な依存パッケージをインストールします。
   ```sh
   # 例: Pythonの場合
   pip install -r requirements.txt
   ```
3. サーバーを起動し、APIエンドポイントにアクセスします。

## APIエンドポイント例
- `/api/cat` : ランダムな猫画像のURLを返します
